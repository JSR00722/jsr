📖 사용법 & 기능 안내

👥 기본 위치 공유

  • 그룹 공유: 동일 그룹명 입력자 간 실시간 위치 지도 공유
  • 내 위치: 지도 위 빨간 원 및 주변 파동(Pulse)으로 표시
  • 일행 위치: 초록색 물방울 마커와 닉네임 라벨로 표시
  • 닉네임 중복 방지: 중복 시 구분 접두사 부여 및 20초 비활성 유저 정리
  • 실시간 날씨 & 미세먼지: 내 위치 기준 날씨/온도/미세/초미세먼지 실시간 표시 (탭하여 즉시 갱신)

🚩 목표 설정 및 도착 알림

  • 목표 지점 (🚩): 빨간 깃발 마커로 목적지 표시
  • 설정 방법 (3가지):
    1. 우측 검색(🔍) 버튼으로 건물/장소/학교 검색 후 지정
    2. 지도 화면의 원하는 지점을 1.5초간 길게 터치하여 지정
    3. 검색 화면 내 '내 현재 위치를 목표로 설정' 클릭
  • 도착 알림: 일행 진입 시(20m 이내) 그룹 전체 기기 토스트 알림 및 진동 전송
  • 자동 해제: 첫 도착자 발생 40분 후 목표 지점 자동 삭제

🛠️ 우측 지도 제어 버튼 (위에서부터)

  • ?
    도움말: 사용법 및 기능 설명 창 표시
  • 초대 QR: 일행 초대용 입장 링크 QR코드 생성
  • 장소 검색: 건물, 학교, 주소 등 목표 지점 검색 및 설정
  • 전체 보기: 나, 일행, 목표를 한 화면에 맞추는 자동 지도 범위 조정
  • 목표 이동: 설정된 목표 지점(깃발)으로 지도 즉시 이동
  • 내 위치 이동: 내 실시간 GPS 위치로 지도 즉시 이동

🚨 긴급 & 편의 기능

  • 🆘 SOS 도움 요청 (좌측 하단): 비상상황 시 전체 기기 긴급 알림/진동 전송 및 내 위치 마커 빨간색(🆘) 점멸 (재클릭 시 취소)
  • 🔋 화면 꺼짐 방지: 로그인 화면 스위치 활성화 시 화면 유지 (배터리 소모량 증가 주의)
  • 🚪 활동 완전히 나가기: 하단 나가기 버튼 클릭 시 저장 세션 삭제 및 퇴장 처리
